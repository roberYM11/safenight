# 실행 검증 기록

검증일: 2026-11-04 KST. CCTV 기능과 Docker 구성을 제거한 현재 코드를 기준으로 한다. 코드 검사, 실제 저장소 시험, 원천 실수집, 배포 서버 검증을 구분한다.

## 로컬 원천 수집과 저장

| 원천 | 조회 구간/기준 | 응답 행 | 고유 revision | 결과 |
|---|---|---:|---:|---|
| S-DoT | 2026-11-03 KST 하루 | 29,200 | 24,715 | 실제 수집·저장 확인 |
| 센서 위치 | 공식 2026-03-10 XLSX | 1,170 | 1,170 | 실제 적재 확인 |

위 수집 결과는 PostgreSQL 16.2에서 확인했다. SQLite 대체 시험이 아니다. 관측 revision 수는 서로 다른 장소의 수와 다르다. 같은 응답의 중복과 정정된 revision을 구분하고, 원문과 실패 이력도 보존했다.

원천의 작은 시계 역전은 관측 시각을 바꾸지 않고 품질 필드에 기록한다. 입력 형식·페이지·시간 범위를 검증하지 못하면 완료 지점을 전진시키지 않는다.

## 현재 코드 검사

| 대상 | 결과 | 범위 |
|---|---|---|
| 로컬 Python | 76개 시험 통과 | 실제 PostgreSQL 저장·rollback·정정·계보·API·스케줄러·모델 경계 |
| 로컬 Python 정적 검사 | Ruff 및 Basedpyright 통과 | 오류·경고 없는 검사 결과 확인 |
| 클라우드 공개 소스 | 87개 시험 통과 | 모델 일치·운영 인증·원천·작업 재개·실제 Miniflare D1/R2·이전 도구 |
| Sites TypeScript·빌드 | 통과 | 서버·화면 타입과 배포 아티팩트 생성 |
| 이전 도구 | 위 87개 중 6개 통과 | 인증 실패·경로 제한·재개·응답 검증 등 클라이언트 경계 |

Sites 시험 중 모델 경계는 Python의 실제 관측 1,169개와 임계값 주변 입력 72개를 비교한다. 반올림 전 점수 차이는 1e-12 미만이다. 실제 D1/R2 시험에서는 여러 페이지의 재개, 완료 전 비공개, 원자적 게시, 잘못된 원문 보존, 반복 페이지와 정정 충돌 격리를 확인했다.

이 수치는 현재 실행한 시험의 결과다. 삭제한 CCTV 시험을 포함한 과거 통과 수치를 최신 결과로 재사용하지 않는다. GitHub Actions 워크플로도 정의했으나 **원격 CI 성공을 이 기록에서 주장하지 않는다**.

## 배포와 클라우드 운영 확인

사이트 주소: [SafeNight](https://safenight-seoul-2026.true-tang-8939.chatgpt.site/).

클라우드 코드의 저장소는 D1과 R2이며, 모델 추론은 서버에서 실행한다. 인증된 import 경로를 통한 기존 데이터 이전은 완료했고 배포 서버에서 다음 값을 다시 읽어 확인했다.

| 이관 대상 | 배포 저장소에서 확인한 값 |
|---|---:|
| S-DoT 관측 revision | 24,715개 |
| 센서 위치 revision | 1,170개 |
| 전체 불변 revision | 25,885개 |
| 현재 선택된 관측·위치 포인터 | 25,885개 |
| 활성 원문 객체 | D1 메타데이터 33개와 대응하는 R2 원문 |

과거 CCTV 응답 원문은 활성 수집 자료와 분리해 R2 백업에 보존했다. 전체 PostgreSQL SQL 압축 백업도 R2에 보관했다. 이전 과정에서 원문 digest와 원래 revision의 legacy ID를 유지했다. 8000·8001 로컬 서버와 SafeNight 전용 Colima 실행을 중지한 상태로 클라우드 이전을 마무리했다.

새 원천 페이지는 R2에 먼저 보존한 뒤 D1에 stage하며, 전체 검증이 끝난 작업만 현재값과 checkpoint에 게시한다. 로컬 API와 Docker를 중지한 상태에서 Sites 서버가 2026-11-03 KST 하루의 S-DoT **29,200행을 직접 수집**했고, 2026-11-04 20:30 KST에 성공 상태를 확인했다. 이번 수집에서 2,700개 revision을 추가했으며, 배포 DB를 다시 읽은 결과 전체 revision 28,585개·현재 포인터 28,585개·활성 원문 메타데이터 180개였다. 위 표는 수집 전 이관 수치다.

Sites에 연결된 클라우드 일정 `SafeNight 공공데이터 수집`을 **매일 03:00 Asia/Seoul, 활성 상태**로 저장하고 다시 조회했다. 첫 예약 시각은 2026-11-05 03:00이며, 이 기록 시점에는 아직 예약 실행 전이다. 정기 실행 자체의 성공을 미리 주장하지 않는다. 데이터 이전, 이번 실제 원천 수집, 일정 저장을 각각 확인한 결과다.

운영자 쓰기 경로는 Site 접근 권한과 별도 토큰을 요구한다. 키·토큰은 Sites 비밀 설정에만 두며, 저장소·브라우저 코드·일정 프롬프트에 포함하지 않는다. 정기 작업 기준은 매일 03:00 Asia/Seoul이고, 완료된 전날·누락 구간·최근 정정 여부를 처리한다.

## 화면과 현재 범위

지도·관측 지점 검색·실험용 표시·관측 시각·조도·소음은 유지하고, CCTV 버튼·주변 조회·영상·인원 검출 경로는 제거했다. 오래된 관측과 입력 부족 상태에서 점수를 만들지 않는다. 모델 버전·평가 수치·수집 진단은 일반 화면에 노출하지 않는다.

새 관측은 모델을 자동 재학습하지 않는다. 센서 위치 파일 새 버전 자동 탐지, 가로등·보안등 수집, 임의 주소의 거리 가중 평가, 안전 경로·실제 SOS 전송은 완료 범위에 포함하지 않는다. 실제 안전 예측력과 운영 부하·장시간 장애 복구는 별도 평가 대상이다.

원본 실적 PDF는 수정하거나 공개하지 않았다. 모델 설명을 제외한 별도 정리본은 [프로젝트 실적 설명서](../docs/project-achievements.md)에 있다.
