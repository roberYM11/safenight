# 실행 검증 기록

검증일: 2026-11-04 KST. 원천의 실수집, 실제 PostgreSQL을 이용한 fixture 시험, HTTP·브라우저 실행을 구분해 기록한다.

## 실제 수집과 저장

| 원천 | 조회 구간/기준 | 응답 행 | 새 revision | 결과 |
|---|---|---:|---:|---|
| S-DoT | 2026-11-03 KST 하루 | 29,200 | 24,715 | 성공 |
| CCTV | 2026-11-03 KST 수정 구간 | 0 | 0 | 성공 |
| 센서 위치 | 공식 2026-03-10 XLSX | 1,170 | 1,170 | 성공 |

네이티브 PostgreSQL 16.2에서 수집을 검증했고, 이후 별도 Docker PostgreSQL 17에도 관측을 적재해 화면과 API를 확인했다. SQLite 대체 시험이 아니다. 원문 객체 34개, S-DoT 관측 revision 24,715개, 센서 위치 revision 1,170개를 보존했다. revision 수는 장소의 수와 다르다.

S-DoT 원천의 일시 형식과 5분 이내 시계 역전은 원본 시각을 바꾸지 않고 품질 필드에 기록한다. 최초 파싱 실패 이력과 원문도 남아 있다. CCTV 변경 조회의 빈 응답은 주변 CCTV가 없다는 뜻으로 해석하지 않는다. 전국 전체 기준 자료는 미적재 상태다.

## API와 Docker

저장소 루트의 Docker 이미지 빌드와 `api`, `db` 컨테이너 실행을 검증했다. 화면과 `/api`는 같은 서버에서 제공하고, DB 포트는 호스트에 공개하지 않는다. 별도 스케줄러는 선택적으로 실행한다.

- `GET /health/ready`: HTTP 200, DB 연결 및 실제 모델 로딩 확인.
- `GET /api/map`: 좌표가 있는 관측 센서 1,169개 반환. 좌표가 없는 50개를 임의 위치에 배치하지 않음.
- `GET /api/assessments/{sensor_id}`: 관측·입력 버전과 점수 또는 산출 불가 상태 반환.
- `GET /api/cctv/nearby`: 실제 행안부 API에 좌표 범위를 전달하고 반경 내 거리를 다시 확인해 가까운 10곳 반환. 검증 지점의 최근접 설치 위치는 약 122m.
- 주변 CCTV 응답의 영상 상태는 `SOURCE_NOT_CONNECTED`. 승인 전 영상 URL이나 인원 수를 만들지 않음.

당시 1,169개 지도 센서 중 625개는 실험용 점수, 나머지는 자료 부족·지원 범위 밖 상태였다. 관측 신선도와 수집 결과에 따라 이후 비율은 달라질 수 있다. 이는 실제 안전 예측력의 검증이 아니다.

## fixture와 정적 검사

```sh
cd backend
uv run ruff check .
uv run basedpyright
# 별도 시험 PostgreSQL 주소를 지정한 상태에서:
uv run pytest -q
```

공개 준비 단계 재실행 결과: **105 passed**, Ruff 통과, Basedpyright 오류 0·경고 0. 실제 PostgreSQL을 지정했으며 DB 통합 시험을 건너뛰지 않았다. XML 실행 기록은 로컬 `backend/var/publication-test-results.xml`에 저장하고 Git에서는 제외한다.

| 원천 어댑터 | 단위·시간대·오류 응답·페이지·좌표·결측과 0 구분 |
| 실제 PostgreSQL 저장 | rollback·정정 우선순위·중복 제거·완료 지점·원문 및 입력 이력 |

원천 HTTP는 fixture 시험에서 대체하고, 실제 공공 API 조회는 별도 실수집으로 확인했다. fixture의 결정론적 predictor는 서비스 모델로 등록하지 않는다. 모델의 새로운 알고리즘·학습 자료에는 별도 평가가 필요하다.

## 화면 확인

프런트엔드 TypeScript 검사, 프로덕션 빌드, 변경한 코드의 린트와 draft guard를 통과했다. 지도 화면의 기본 상태·주변 CCTV 조회 결과·결과 끝까지 스크롤한 상태를 390px와 1440px, 밝은/어두운 테마에서 정리 전후로 비교했다.

일반 화면에서 모델 이름·평가 수치·학습 변수·수집 진단 탭·중복 CCTV 미집계 카드를 제거했다. 지도, 검색, 실험용 표시, 환경 관측값, 관측 시각, 주변 조회와 산출 불가 상태는 유지한다. 프런트엔드는 모델 메타데이터나 `/sources` 응답에 의존하지 않는다.

Lighthouse 전 항목 통과나 코드 전체의 react-doctor 무결점은 주장하지 않는다. 기존 시연용 파일은 현재 앱에서 실행하지 않으며, 실제 SOS·경로 추천·승인된 영상·인원 집계는 완료 기능에 포함하지 않는다.

## 보존 범위와 남은 검증

API 키, DB 비밀번호, `.env`, DB 볼륨, 개발 캐시와 로컬 증빙 이미지는 공개 저장소에서 제외한다. 원본 실적 PDF도 수정하거나 공개하지 않고 모델 설명을 제외한 정리본을 별도로 작성했다.

실제 안전 예측력, 운영 부하, 장시간 장애 복구, 상시 스케줄러 운영, 가로등·보안등 집계, 영상 분석은 별도 검증·구현 대상이다. 새 입력을 요구하는 모델은 수집과 feature 계약도 바꿔야 한다.
