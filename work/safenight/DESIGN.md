# SafeNight 화면 기준

## 1. 방향과 근거

기존 GitHub 원본과 같은 로컬 `Home.tsx`, `MapVisualizer.tsx`, `BottomSheet.tsx`를 기준으로 유지한다. 지도가 화면 전체를 채우고 SafeNight 방패 로고, 상단 검색, 우측 점수·위치 버튼, 하단 둥근 정보 패널이 겹치는 구조다. 새로운 대시보드로 바꾸지 않는다.

2026-11-04 변경 전 Chrome `127.0.0.1:3000/#/home`을 CUA로 확인하고 스크린샷을 캡처했다. 기존 CARTO 타일의 API KEY REQUIRED 응답, 고정 점수, 실제 동작하지 않는 SOS·영상 표시는 새 데이터 연결 화면에서 제거한다. 레거시 파일은 보존하고 새 진입 화면에서는 사용하지 않는다.

디자인 지침: omo:frontend의 기존 UI 추출 분기, layout-skill의 스크롤 소유권, perfection 및 React dev tooling, omo:programming의 TypeScript 경계 검증을 적용한다. 지도 위 레이어 구조는 StyleGallery의 overlay-stack을 참고한다. 외부 자료의 문구·코드는 복제하지 않는다.

## 3. 글자

시스템 한국어 sans-serif: `-apple-system, BlinkMacSystemFont, Segoe UI, sans-serif`. 계측·센서 식별자는 시스템 monospace. 크기는 12px(메타), 14px(보조), 16px(본문), 20px(패널 제목), 24px(로고), 44px(점수). 본문 줄 높이는 1.5, 헤드라인은 1.2. 센서 ID와 모델 버전은 줄바꿈을 허용한다.

## 4. 간격과 레이아웃

간격 토큰은 4, 8, 12, 16, 20, 24, 32px. 모서리는 8px(작은 컨트롤), 16px(입력·점수 패널), 24px(하단 패널), 원형(아이콘 버튼). 터치 영역은 최소 44px. 중립 1px 경계와 면의 명도로 깊이를 구분하고 지도 위 패널에만 기존 방식의 절제된 그림자를 적용한다.

Layout: SafetyMap - 전체 지도에 검색·점수·측정 정보를 겹쳐 표시 -> overlay-stack (https://github.com/changeroa/StyleGallery/blob/main/patterns/overlay-exception/overlay-stack.md); scroll owner: .sheet-content; anti-patterns: 지도와 컨트롤의 초점 순서를 시각 배치와 다르게 바꾸지 않고 문서 전체와 패널이 동시에 스크롤하지 않게 한다.

상단 헤더와 지도는 고정된 100dvh shell 안에 있다. 하단 패널 본문 하나가 스크롤한다. 검색 결과 팝업만 최대 높이를 가진 독립 검색 스크롤이다. 390px에서는 검색이 헤더 아래 한 줄, 점수는 우측, 하단 패널은 너비 전체다. 1440px에서는 같은 지도 중심 구조를 유지하며 검색 최대 512px, 하단 패널 콘텐츠 최대 1120px를 사용한다. 콘텐츠가 길어도 수평 스크롤이 생기지 않는다.

## 5. 화면과 재사용 컴포넌트

주요 동작은 관측 지점 선택이다. 정보 우선순위는 선택한 지점의 실험용 환경 안전도, 관측 시각과 실제 측정값, 주변 CCTV 위치 순이다. 사용자 화면에서는 모델 버전·검증 지표·수집 작업 상태, 중복 CCTV 미집계 카드, 서버 재시작 안내를 제외한다. 이 개발 정보는 백엔드 API와 저장소 문서에서 관리한다. 모의 영상, 모의 긴급 전송, 장식용 통계 카드는 넣지 않는다.

필수 내용: SafeNight 로고, 관측 지점·지역 검색, 테마 변경, 자료 새로고침, 지도 관측 지점 선택, 전체 지점 목록, 위치 이동, 선택 지역·관측 시각·점수 또는 불가 사유, 조도 lux·소음 dB, 요청할 때 주변 CCTV 위치 조회, 영상 미연결 안내, 실제 범죄·사고 확률이 아니라는 설명. 같은 지역의 지점을 구분하기 위한 센서 ID는 목록의 보조 정보로만 유지한다.

- IconButton: 접근 가능한 이름·title, 기본/hover/pressed/focus/disabled, 44px 이상.
- SensorMap: 실제 센서 마커만 사용. 선택·타일 오류 상태. 키보드 사용자는 동일 센서 목록으로 선택한다.
- Search field/results: label과 Escape 닫기, 검색 결과 0건 안내, 센서 이름/ID 선택.
- Sensor row: 센서 ID를 안정적인 key로 사용, 선택 면과 체크 아이콘, nullable 점수.
- Bottom sheet: 관측값/관측 지점 탭, 키보드 순서·aria 선택 상태, 접기/펼치기 버튼.
- Measurement: 실제 값과 단위 또는 미확인 상태. 결측을 0으로 바꾸지 않는다.
- Score: 선택 값만 표시. 요청 실패 시 이전 점수를 지우고 재시도 동작 제공.

## 6. 동작과 비동기 상태

서버를 60초마다 다시 조회한다. AbortController로 교체된 요청과 해제된 화면을 취소한다. 대기·빈 목록·조회 실패·오프라인 상태를 제공한다. 새로고침 시 요청 중임을 즉시 표시하고 이전 요청의 늦은 결과가 상태를 덮지 않도록 한다. 점수는 API 응답만 사용한다.

버튼 피드백은 120ms opacity/transform. 지도 이동은 reduced-motion을 존중한다. 의미 없는 반복 애니메이션은 없다. 개발 도구는 DEV 분기에서만 로딩하며 production 번들에 포함하지 않는다.

## 7. 접근성과 검증

WCAG AA 대비와 눈에 보이는 초점을 목표로 한다. 아이콘 버튼은 이름을 갖고 input은 label을 갖는다. 점수와 자료 상태는 텍스트로 읽을 수 있다. 지도만으로 정보를 접근하게 하지 않는다. 모바일/데스크톱·light/dark 및 로딩/실패/빈 결과의 최종 브라우저 검수는 주 작업자가 수행한다.

변경 전 캡처는 CUA 도구 결과로 기록되어 있고 별도 PNG 파일은 저장되지 않았다. 현재 위치는 사용자가 버튼을 누를 때만 브라우저에 요청한다. 외부 역지오코딩으로 개인 위치를 전송하지 않는다.

2026-11-04 사용자 화면 정리 전후 캡처는 `.omo/evidence/ui-cleanup/`에 390px·1440px 및 두 테마로 저장한다. 기존 overlay-stack과 `.sheet-content` 스크롤 소유권을 유지한다. 하단은 두 측정값과 CCTV 조회 한 곳으로 정리한다.

지도 제공처 표시는 하단 패널 바로 위 지도 중앙에 항상 노출한다. OSM·Leaflet 링크의 높이는 기존 터치 기준인44px로 유지하며, 하단 패널·좌측 확대 버튼·우측 지도 버튼과 겹치지 않게 배치한다.

## 8. 요청할 때 CCTV 찾기

관측값 패널의 ‘주변 CCTV 찾기’를 누를 때만 반경 1km의 저장된 설치정보를 조회한다. 기본 로드·60초 관측 갱신은 이 조회를 실행하지 않는다. 센서 변경·패널 닫기·조회 닫기는 진행 중인 요청을 취소하고 이전 결과를 버린다. 영상 제공처 미연결 상태에서는 분석 실행이나 인원 수를 표시하지 않으며 필요한 설정을 안내한다. 기존 패널 스크롤·버튼 토큰을 사용한다.
