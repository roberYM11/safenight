# SafeNight 프런트엔드

지도에서 관측 지점을 선택하고 실험용 환경 안전도, 조도·소음, 주변 CCTV 설치 위치를 확인하는 React·Vite 화면입니다. API 키는 프런트엔드에 넣지 않습니다.

## 개발 실행

백엔드가 `http://127.0.0.1:8000`에서 실행 중이어야 합니다.

```sh
npm ci
npm run dev
```

`http://127.0.0.1:3000`에서 확인합니다. 개발 서버는 `/api` 요청을 백엔드에 전달합니다.

## 확인과 빌드

```sh
npx tsc --noEmit
npm run build
```

`dist/`는 생성 결과이며 저장소에 올리지 않습니다. 전체 서비스 실행, 데이터 수집, Docker 및 모델 교체 절차는 [프로젝트 설명](../../README.md)을 확인하세요.
