# 원본과 이번 정리의 구분

## 원본 프로젝트

사용자가 제공한 프로젝트는 밤길 안전도 예측을 목표로 했다. 원본 Drive에는 환경·시설 자료 결합, 수동 지수 설계, Random Forest와 Optuna 실험, 다이어그램이 있다. 원래 나무 설정과 목표식은 이번에도 보존했다.

`archive/original_preprocessing.ipynb`, `archive/original_model.ipynb`, `archive/original_design.drawio`는 원본 자료 사본이다. 원본 노트북은 학습 기록 보존용이며 최신 실행 진입점은 src다. 원본 셀을 이번 수정 내용으로 덮어쓰지 않았다.

## 2026-10-30 재검증

원시165,476행과 기존3,713행을 비교해 여섯 열 이동을 찾고 실제 조도·소음 입력3,619행을 복원했다. 시설 좌표 반복, 데이터 범위, 목표식, 원래 시험셋 재사용, 좌표 중복을 점검했다. 기존 고정파라미터 6개 진단은 `results/legacy-model-diagnostics.json`과 `docs/PROJECT_EVIDENCE.md`에 남겼다.

## 2026-10-31 최종 정리와 사이트 재구성

추가 좌표 검사로2센서11행을 제외하고3,230행을 구성했다. 같은 좌표 분리5-fold에서4모델을 비교했다. OOF 예측, 학습 모델, 재현 스크립트와 테스트를 생성하고 로컬 지도 사이트를 새로 구현했다. 이 단계는 사용자의 요청에 따라 AI 코딩 도구와 함께 진행한 재검증·재구성 작업이다. 새 사이트와 비교 실험을 작년 원본 구현의 성과로 소급하지 않는다.

README의 데이터 결합 설명과 모델 선택 근거는 원본 코드 구조와 이번 실제 비교 결과를 바탕으로 정리했다. 사용자가 당시 수행한 생각의 정확한 순서를 확인할 자료가 없는 부분은 구체적인 경험담으로 만들어 넣지 않았다.
