# SafeNight 데이터·모델 검증 기록

확인일: 2026-10-30. 원본 파일을 수정하지 않고 전처리 계보와 모델 평가를 재구성했다. 원본 노트북의 저장 출력과 이번에 실행한 진단 결과를 구분한다.

CCTV 원본은 노트북에 기록된 Drive ID를 현재 계정으로 조회하면 404가 반환된다. 이번 재실험은 학습 CSV에 저장된 CCTV 집계값을 유지했다. 삭제와 권한 문제 중 어느 경우인지 확정하지 않았다.

## 원시 열 대응 오류

`raw_sdot.csv`의 헤더는 58개이고, 데이터 행은 전부 64개 필드다. 165,476행 모두 뒤의 6개 필드가 빈 문자열이다. 기존 로딩 코드에는 이 폭 차이를 처리하는 설정이 없다. 노트북은 이후 `reset_index()`로 생성된 `level_1`을 시리얼, `level_2`를 시각으로 사용한다. 즉 앞의 6개 필드가 묵시적 인덱스로 해석된 상태와 일치한다.

원시 파일의 실제 위치는 다음과 같다. 위치 번호는 0부터 센다.

| 원시 위치 | 원시 헤더 | 기존 가공본에서 붙은 이름 |
| --- | --- | --- |
| 18~20 | 조도 최대·평균·최소(lux) | 해당 값은 기존 학습에 사용되지 않음 |
| 24~26 | 소음 최대·평균·최소(dB) | 조도 최대·평균·최소(lux) |
| 30~32 | 진동(y) 최대·평균·최소 | 소음 최대·평균·최소(dB) |

시리얼→위치 결합을 원본 순서대로 재구성한 결과 기존 3,713행의 병합 인덱스·시각·좌표가 모두 일치했고, 위 6칸 이동에 따른 측정값의 불일치 행도 0개였다. 단순 범위 추정이 아니라 전 행 대조 결과다.

기존 모델 노트북은 잘못 붙은 ‘소음’ 열에 1,000을 곱했다. [서울시 원자료 공지](https://data.seoul.go.kr/dataList/OA-15969/S/1/datasetView.do)는 2022.12~2026.10 진동 단위가 `mm/s`에서 `g`로 정정되었다고 명시한다. 이는 단위 표기 정정이며, 진동을 dB로 변환하는 근거가 아니다.

## 공간 결합·시설 수

원본 코드는 위경도를 라디안으로 변환하고 Haversine BallTree에서 `r=25/6371000`으로 검색한다. 재집계한 보안등·가로등 행 수는 저장 CSV와 3,713행 모두 일치했다.

| 자료 | 파일 행 수 | 유효 위경도 행 | 고유 유효 좌표 | 발견 |
| --- | ---: | ---: | ---: | --- |
| 보안등으로 사용한 파일 | 195,702 | 195,702 | 144,187 | 한 좌표의 최대 반복 807행 |
| 가로등 | 19,316 | 19,291 | 19,291 | 25행은 위경도 범위 밖 |

보안등 저장 집계 최댓값 221은 센서 좌표 `(37.545028041, 126.864660671)` 주변의 사례다. 그 반경에 포함된 보안등 221행은 고유 좌표 1개다. 고유 좌표만 세면 전체 표본의 보안등 집계 최댓값은 8이다. 좌표가 같다고 물리 시설이 반드시 하나라는 뜻은 아니며, 원본 식별자 없는 현재 자료로 실제 장치 수를 확정할 수 없다.

가로등의 범위 밖 좌표 25행을 제외해 재집계해도 저장된 25m 개수는 변하지 않았다. 시설의 실제 작동 여부, CCTV 방향, 건물에 의한 가림은 검증하지 않았다.

[가로등 공식 페이지](https://data.seoul.go.kr/dataList/OA-22205/F/1/datasetView.do)는 서울시 도로사업소·서울시설공단 관리 시설을 대상으로 한다. 프로젝트의 20221108 파일과 현재 배포 파일의 동일성은 확인하지 않았다. 보안등 파일의 정확한 공식 원본 연결도 미확정이다.

## 원본 목표값 수식

각 입력은 비음수인 경우를 기준으로 설명한다.

```text
I = clip(100 - L/3, 0, 100)

N = clip(100 - 2.5n, 0, 100)              if n < 40
    (n - 40) × 20/30                     if 40 ≤ n ≤ 70
    min(100, 20 + (n - 70) × 80/40)      if n > 70

v = (소음 최대 - 소음 최소)/4
T = 50                                   if n = 0
    clip(50 - 100v/(n + 0.00001), 0, 100) otherwise

C = min(100, 25 × CCTV 좌표 행 수)
G = min(100, 20 × 가로등 좌표 행 수)
B = min(100, 30 × 보안등 좌표 행 수)

S = clip(100 - 0.30I - 0.15N - 0.10T + 0.25C + 0.15G + 0.05B, 0, 100)
```

`L`은 평균조도, `n`은 평균소음이다. `v`는 시계열 표준편차가 아니며, dB 값의 비율을 유동인구 변동으로 보정한 실험도 없다. 원본 식에서 `T≤50`이므로 `H≤50`, 따라서 `S≥50`이다. 가중치·300 lux·소음 경계·25m 반경을 실증 자료로 보정한 근거는 없다.

잘못 명명된 기존 입력으로 이 식을 계산하면 저장 목표값 3,713행과 모두 일치한다. 복원된 3,619행에 같은 식을 적용하면 기존 같은 행의 지수와 평균 절대차가 4.971419점이다. 기존 전체와 복원된 부분집합의 평균을 단순 전후 비교하지 않았다.

복원 표본의 가중 기여값 분산은 조도 16.5302, 소음 0.3014, 소음 변동 0.0320, CCTV 78.8687, 가로등 0.1505, 보안등 3.9097이다. 명목 가중치가 가장 크다는 이유만으로 조도가 실제 예측값 변동을 가장 많이 설명한다고 말할 수 없다. 공분산과 clipping이 있으므로 이를 합계 대비 설명력 비율로 해석하지 않았다.

## 기존 실험과 재실험

원본 노트북 셀 번호는 0부터 센다. 셀 27은 10개 입력과 `safety_index`를 지정하고, 셀 28은 `train_test_split(random_state=42, test_size=0.2)`를 실행한다. 셀 29의 Optuna 100회가 동일 테스트셋 MSE를 선택 기준으로 사용하며, 셀 33이 그 테스트셋을 최종 평가에 재사용한다.

저장된 과거 출력은 RMSE 0.3794, R² 0.9987, MSE 0.1439다. 원래 저장 실행과 현재 런타임을 동일시하지 않는다.

재실험 환경은 NumPy 2.3.5, scikit-learn 1.9.0이다. 다음 파라미터를 모든 비교에서 고정했다. 새 Optuna 탐색은 수행하지 않았다.

```text
n_estimators=114, max_depth=18, min_samples_split=2,
min_samples_leaf=1, max_features=None, bootstrap=True,
random_state=42, n_jobs=1
```

행 분할은 원본과 같은 방식이다. 좌표 분할은 위도·경도 쌍을 그룹으로 둔 `GroupShuffleSplit(n_splits=1, test_size=0.2, random_state=42)`이다. 서로 다른 좌표라도 근접할 수 있으므로 완전한 공간 독립성이나 거리 버퍼 분할로 표현하지 않는다.

| 입력/목표값 | 분할 | 훈련 / 평가 | RMSE | R² |
| --- | --- | ---: | ---: | ---: |
| 기존 저장 자료 3,713행 | 행 | 2,970 / 743 | 0.3807 | 0.9987 |
| 기존 저장 자료 3,713행 | 좌표 | 2,971 / 742 | 0.8273 | 0.9937 |
| 입력 복원 3,619행 | 행 | 2,895 / 724 | 0.3288 | 0.9988 |
| 입력 복원 3,619행 | 좌표 | 2,902 / 717 | 1.2305 | 0.9833 |
| 입력 복원·중복 제거 3,240행 | 행 | 2,592 / 648 | 0.2633 | 0.9993 |
| 입력 복원·중복 제거 3,240행 | 좌표 | 2,594 / 646 | 1.2121 | 0.9838 |

기존 행 분할의 평가 743행 중 훈련과 좌표가 겹치는 행은 743개, 10개 입력까지 동일한 행은 168개다. 중복 제거 후에도 입력의 양자화·시설 수 일치 때문에 다른 센서·시각에 동일 입력 벡터가 생긴다. 좌표 분할은 좌표 겹침만 제거한다. 다른 좌표에 동일 입력 벡터가 있는 것 자체를 정보 누출로 단정하지 않는다.

중복 제거 후 훈련 평균값만 예측하는 기준선 RMSE는 행 분할 9.7306, 좌표 분할 9.5374다. 모델이 규칙 목표값을 평균 기준선보다 잘 재현하는 것은 확인되지만, 목표값 자체의 실제 안전 타당성을 검증한 것은 아니다. 기존 선택 파라미터·단일 시드·동일 날짜 자료의 진단 결과이며, 실제 사고·범죄·체감 안전 라벨은 추가되지 않았다. 모델 바이너리를 역직렬화하거나 새 배포 모델을 저장하지 않았다.
