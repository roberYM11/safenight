# 데이터 사전과 출처

한 행은 센서 ID 하나가 2025-10-12의 특정 시각에 기록한 관측이다. 최종 3,230행·652좌표. 시간별 자료이지 보행자 개인·범죄 사건·도로 구간별 정답 자료로 수집한 행은 아니다.

## 처리 계보

원시 센서 165,476행 → 원본 선택 복원 3,713행 → 실제 조도·소음 모두 존재 3,619행 → 좌표가 뒤바뀐 형태의 2센서 11행 제외 3,608행 → 동일 센서·시각 중복378행 제거 → 3,230행.

이전 3,240행은 좌표 유효성 제외 전 진단이다. `OC3DL230025`, `OC3DL230026`는 위도 열에126대, 경도 열에37대가 기록돼 있다. 두 좌표를 단순 교환해도 이전 주변 시설 집계의 정확성은 별도 문제가 남아 이번 실험에서 제외했다. `excluded_coordinates.csv`는 그 원본11행이다. 전역 한국 좌표 범위 33~39°N,124~132°E를 기본 검증 가드로 사용했으며 서울 행정경계 판정은 수행하지 않았다.

`data/intermediate/restored_candidates.csv`는 복원된 후보이며 `src/prepare.py`의 입력이다. `data/processed/restored_observations.csv`에는 첫 동일 센서·시각 관측만 남긴다. 반복 입력이 충돌하면 스크립트가 멈추도록 구성했다. 원시 행 번호는 보존한다.

## 열

| 열 | 형식·단위 | 의미 |
| --- | --- | --- |
| raw_index | 정수 | 원시 센서 CSV의 0부터 시작하는 데이터 행 번호 |
| sensor_id | 문자열 | 센서 일련번호 |
| time | YYYY-MM-DD_HH:mm:ss | 원본 관측 현지시각 |
| lat, lon | 소수도, WGS84 가정 | 설치 위치에서 연결한 좌표 |
| lux_max, lux_avg, lux_min | 실수, lux | 실제 원시 조도18~20열 복원값 |
| noise_max, noise_avg, noise_min | 실수, dB | 실제 원시 소음24~26열 복원값 |
| noise_range_proxy | 실수 | (noise_max-noise_min)/4 |
| cctv, light, security | 실수 형태의 정수 집계 | 기존 노트북의 반경25m 좌표 행 수 |
| old_target | 실수, 점 | 열 이동이 있던 원본의 기존 지수. 계보 확인용이며 새 학습 입력·목표에서 제외 |

예측 CSV의 rule_index는 복원 입력으로 재계산한 지수, oof_prediction은 해당 좌표를 제외하고 학습한 Random Forest 예측, fold는 0~4평가 폴드다.

최종 평균조도0~467lux, 중앙값0, 0인행1,911/3,230(59.16%). 평균소음35~74dB, 중앙값43. 가로등0인행3,200/3,230(99.07%). 보안등최대221, 중앙값0. 시설의 드문 큰값과 0분포를 확인할 수 있도록 `results/benchmark.json`에 모든10변수의 범위·중앙값·0개수를 저장했다. 센서0은 관측 해석과 센서상태 검토가 필요한 값으로 보존했다.

## 원본과 공식 자료

- [S-DoT 환경정보](https://data.seoul.go.kr/dataList/OA-15969/S/1/datasetView.do): 원시 주간파일, 2025-10-06~12. 헤더58/필드64 문제와 진동단위 정정 공지를 확인한 원천.
- [현재 S-DoT 데이터](https://data.seoul.go.kr/dataList/OA-22833/A/1/datasetView.do): 재연결 후보. 현재 사이트는 포함한 파일만 읽는다.
- [가로등 위치](https://data.seoul.go.kr/dataList/OA-22205/F/1/datasetView.do): 도로사업소·서울시설공단 관리범위.
- 원본 보관 자료: 위치 workbook, 원본 중간 CSV, 모델 CSV, 보안등으로 사용한 `SMG_27_20221107_C_001.csv`, 가로등 CSV. 공개 저장소에는 개인 보관 링크를 포함하지 않았습니다.
- CCTV는 원본 Drive 파일 접근404로 원자료 재대조를 완료하지 못해 저장된 집계를 유지했다. 보안등 파일과 공식 배포 파일 사이의 정확한 연결도 미확정이다.

개인 위치 이력은 포함하지 않는다. 좌표는 공개 설치 센서의 위치이며 파일에는 이름·계정·연락처·API키가 없다. 원천 자료의 재사용 조건은 각 배포 페이지를 따른다. 출처가 미확정인 시설 자료에 임의의 오픈 데이터 라이선스를 부여하지 않았다. 대용량 원시 자료는 원본 출처에서 받을 수 있고, 저장소는 분석에 쓰인 파생 표본과 계보를 제공한다.
