# 주변 CCTV와 영상 연결

‘주변 CCTV 찾기’는 클릭할 때만 실행합니다. 현재 승인된 행안부 API로 선택 좌표 주변 설치정보를 직접 검색하도록 고쳤습니다. 전체 CCTV 자료를 미리 저장할 필요가 없고, 기본 반경은 1km입니다. API 좌표 조건의 경계 사각형을 조회한 뒤 Haversine 거리로 원형 반경을 검증합니다. 최대 500행·8초 제한에 걸린 결과는 불완전할 수 있음을 표시합니다.

설치정보와 영상 접근을 구분합니다. 공공 영상 API 승인을 아직 받지 않은 상태이며, ITS 공개 test 응답은 요청 영역과 다른 고정 예제를 반환했고 첫 영상 주소도 HTTP 401이었습니다. 해당 예제를 실제 주변 영상으로 넣지 않았습니다. 영상 승인을 받았다고 자동으로 인원 집계까지 연결되는 것도 아닙니다. 현재 인원 분석은 미구현입니다.

## 허가받은 영상 연결

운영자가 확인한 공개 HTTPS 영상 소스 목록을 JSON 파일로 설정할 수 있습니다. 필수 필드는 `camera_id`, `name`, `lat`, `lon`, `playback_url`, `playback_type`, `source_url`입니다. `playback_type`은 `hls`, `mp4`, `external` 중 하나입니다. 실제 촬영 위치를 넣어야 하며, URL의 재생·표시 권한과 유효기간을 확인해야 합니다. 자료 없는 위치에 예제 영상을 배치하지 마십시오.

로컬 서버는 `.env`의 `SAFENIGHT_VIDEO_CATALOG_FILE`에 해당 파일 경로를 설정한 뒤 다시 시작합니다. 파일은 서버 설정으로만 선택하며, HTTP 요청으로 임의 URL을 받거나 서버가 영상을 대신 다운로드하는 프록시는 제공하지 않습니다. URL의 HTTPS 호스트와 자격 증명 포함 여부를 검증하고 IP 리터럴·localhost·local/internal 호스트를 거절합니다.

Docker에서는 승인된 목록을 컨테이너의 `/app/var/video_sources.json`에 복사하고, `.env`에 `SAFENIGHT_VIDEO_CATALOG_FILE=/app/var/video_sources.json`을 설정한 뒤 `sh scripts/docker-local.sh up -d --force-recreate api`로 설정을 반영합니다. `/app/var`는 별도 runtime volume이므로 코드 재빌드로 없어지지 않습니다. 빈 목록은 영상 후보를 만들지 않습니다.

프런트엔드는 목록 조회만으로 영상을 연결하지 않습니다. 사용자가 ‘주변 영상 보기’를 누른 다음 재생기를 생성합니다. HLS는 브라우저의 native 지원 또는 hls.js를 사용합니다. 영상 닫기·조회 닫기·센서 변경·패널 해제 시 HLS 연결과 video src를 해제합니다. 제공처 CORS·인증·만료·브라우저 제한으로 실패하면 재생 실패와 제공처 링크를 표시합니다. 접근 가능한 URL이라는 사실만으로 지연 없는 실시간이라고 표시하지 않습니다.

## 실제 검증

- 행안부 API 실측: 좌표 조건 검색 성공. 검증한 성산동 센서 지점 주변 사각형에서 201행을 받고, 반경 1km 안에 123개 시설 좌표가 있었으며 가장 가까운 거리는 약 121.9m였습니다. 자료가 갱신되면 결과는 달라집니다.
- Docker 사이트 브라우저에서 실제 버튼 클릭 후 가까운 10곳과 첫 후보 약 122m 표시를 확인했습니다.
- pytest 97개 통과, Ruff 통과, Basedpyright 오류·경고 0개. 영상 URL 검증·주변 거리 필터·실시간 공급처 fixture가 포함됩니다.
- 실제 공공 도로 영상의 재생·프레임 지연·인원 검출 성능은 영상 승인 전이므로 미검증입니다. 영상 재생기의 코드·경계 테스트를 실제 주변 영상 재생 성공과 구분합니다.

공식 안내: [행안부 CCTV 설치정보](https://www.data.go.kr/data/15155042/openapi.do), [UTIC 영상 이용](https://www.utic.go.kr/guide/utisRefCctv.do).
