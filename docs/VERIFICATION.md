# 최종 검증 기록

2026-10-31 기준으로 SafeNight의 데이터 처리, 모델 산출물, 지도 화면을 다시 확인했습니다.

## 코드와 데이터

- `uv run src/prepare.py`로 원본 후보를 재구성하고, 좌표가 뒤바뀐 센서 2개의 11개 행을 제외했습니다.
- 최종 표본은 3,230개 관측 행, 652개 좌표입니다.
- `uv run --with pytest --with numpy==2.3.5 pytest -q` 결과: 6 passed.
- `node --check site/app.js` 결과: 통과.
- `uv run src/train.py`를 다시 실행해 처리 데이터, OOF 예측, 모델 파일, 화면용 데이터를 같은 입력에서 생성했습니다.

좌표 단위 GroupKFold 5개 폴드에서 Random Forest의 결과는 RMSE 0.8849, MAE 0.3505, R² 0.9912입니다. 이 값은 실제 범죄 확률의 정확도가 아니라, 프로젝트가 정의한 규칙 지수를 모델이 얼마나 재현하는지를 나타냅니다.

## 화면

- 지도 타일이 지연되거나 끊겨도 관측 좌표와 검색은 계속 사용할 수 있도록 처리했습니다.
- 센서 ID·좌표 검색, 시간 변경, 지도 원 클릭, 지점 선택, 같은 장소의 시간 비교, 선택 지점 이동을 확인했습니다.
- 모바일 폭과 데스크톱 폭에서 레이아웃을 확인했고, 화면은 다크 테마를 기본으로 사용합니다.
- 지도 확대·축소 버튼은 터치 가능한 44px 크기로 설정했습니다.

## 해석 범위

현재 화면은 2025년 10월 12일의 저장된 관측 표본을 탐색합니다. 서울시 API의 실시간 재연결은 별도 작업이며, 현재 결과를 실제 위험 발생 확률이나 경로 추천으로 해석하지 않습니다.
