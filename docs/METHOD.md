# 수식과 실험 조건

조도·소음과 주변 시설을 조합한 지수를 학습 목표로 사용했다. 목표값은 `src/scoring.py`에서 계산하고 `src/train.py`에서 모델을 학습·비교한다. 범죄·사고의 관측값을 목표로 학습한 실험과는 구분한다.

L=평균조도, n=평균소음, v=(소음최대-소음최소)/4.

```text
I = clip(100 - L/3, 0, 100)
N = clip(100 - 2.5n, 0, 100)                 if n < 40
    (n - 40) × 20/30                       if 40 ≤ n ≤ 70
    min(100, 20 + (n - 70) × 80/40)         if n > 70
T = 50                                     if n = 0
    clip(50 - 100v/(n+0.00001), 0, 100)     otherwise
C = min(100, CCTV좌표행수 × 25)
G = min(100, 가로등좌표행수 × 20)
B = min(100, 보안등좌표행수 × 30)
S = clip(100 - .30I - .15N - .10T + .25C + .15G + .05B, 0, 100)
```

비음수 입력에서 T≤50이므로 환경 부담 최대는 50이며 최종 지수는 50~100에 놓인다. v는 실제 시계열 표준편차와 구분한다. dB 범위를 평균 dB로 나눈 값의 물리적 의미와 사람 활동성의 관계는 검증 대상으로 남긴다.

시설 0은 제공된 좌표 자료의 반경 집계 0이다. 실제 시설 부재와는 제공 범위·좌표 중복·시야·운영 상태가 다를 수 있다. 원본 반경25m와 원본 시설 집계를 비교의 고정 조건으로 유지했다.

## Haversine 거리

위도·경도는 평면 좌표처럼 바로 빼지 않고 Haversine 공식으로 구면상의 두 점 사이 최단 거리를 계산한다. 두 점의 위도·경도를 라디안으로 바꾼 뒤 `a = sin²(Δ위도/2) + cos(위도1) × cos(위도2) × sin²(Δ경도/2)`, `d = 2R × asin(√a)`를 적용한다. 여기서 `R`은 지구를 구로 근사한 반지름 6,371,000m다. 건물·도로·횡단보도를 고려한 보행 거리가 아니라 두 좌표 사이의 구면 거리다. `BallTree(metric="haversine")`는 좌표를 묶어 탐색하며 반경 `25 / 6371000`라디안 안의 시설 행을 찾는다.

현재 위치 추정에서는 같은 계산으로 위치와 센서 사이의 `d_m`을 구한다. 같은 시각의 가까운 센서 최대 8개를 고르고 `w = 1 / (d_m + 8)^2`와 `Σ(w × 값) / Σw`를 적용한다. 예를 들어 거리가 각각 92m, 192m이면 가중치 비율은 4:1이다. 8m는 거리 0에서도 가중치가 유한하도록 두는 완충값이며 실측으로 최적화한 값은 아니다.

사이트는 센서별 OOF 예측값과 규칙 지수, 환경값·시설 집계를 각각 가중 평균한다. 평균낸 입력을 Random Forest에 새로 넣는 방식이 아니다. 시설 집계의 소수는 주변 센서 집계의 보간값이며 현재 위치 반경 25m 안의 시설을 직접 센 값과 구분한다. 센서와 정확히 같은 위치에서도 같은 가중식을 적용하며, 현재 구현에는 최대 탐색 반경이 없어 센서가 멀면 추정 근거도 약해진다.

## 현재 모델 비교

3,230행, 652개 좌표, 10개 수치 변수. GroupKFold(n_splits=5), 기본 shuffle=False, 좌표 문자열을 그룹으로 고정. 같은 좌표의 모든 시각은 같은 평가 폴드다. 각 폴드의 학습과 평가 좌표 교집합이 비었는지 검사한다. 공간 버퍼·시간 외삽 검증은 추가하지 않았다. 원본 파라미터를 이미 선택한 과정과 이번 고정 폴드 진단을 구분한다.

학습 평균값, LinearRegression 기본값, DecisionTreeRegressor(depth18,seed42), RandomForestRegressor(114trees,depth18,minsplit2,minleaf1,max_features=None,bootstrap=True,seed42,n_jobs1)를 비교했다. 목표식은 입력에서 계산한다. OOF 총 RMSE는 모든 평가 예측의 제곱오차를 모아 계산하며 폴드 RMSE 단순 평균과 구분한다.

Random Forest는 복원 추출한 학습 행으로 각 나무의 부트스트랩 표본을 만든다. 각 나무는 제곱오차가 줄어드는 입력 변수·임계값으로 표본을 나누며, 마지막 잎에 모인 목표값의 평균을 예측한다. 최종 예측은 114개 나무 예측의 평균이다. `max_features=None`이므로 분할 후보로 전체 10개 변수를 검토한다. 변수 단위가 서로 달라도 각 변수 안의 임계값으로 나누므로 거리 기반 모델처럼 단위가 큰 변수가 거리 계산을 지배하지 않는다.

Random Forest는 표 형식의 비선형 변수 관계와 서로 다른 단위를 다루는 후보로 합리적이다. 이번 실험의 가장 작은 오차는 선택 근거를 보완하지만 일반적인 우월성을 뜻하는 통계 검정은 수행하지 않았다. 선형 회귀는 특정 폴드 오차가 커서 총 RMSE와 MAE를 함께 제시했다. 반복적 파생변수와 최대·평균·최소의 상관도 고려해야 한다. 변수 중요도를 실제 안전의 원인으로 해석하는 실험은 수행하지 않았다.

규칙을 직접 계산하면 현재 목표에 대한 오차는 0이다. 회귀 모델은 이 규칙에 대한 대체 추정 실험이며 현재 수식보다 더 좋은 안전 정답을 만드는 역할을 평가한 것은 아니다. 독립적 안전 관측을 수집하면 현재 입력 구성과 좌표 분리 구조를 새로운 목표 검증에 재사용할 수 있다.
