# SafeNight

**서울시 환경 관측을 수집·보존하고 지도에서 확인하는 웹서비스**

밤길의 주변 환경을 살펴볼 때 관측값과 관측 시각을 함께 확인하도록 만들었습니다. 서울시 S-DoT의 조도·소음을 센서 위치와 연결하고, 지도에서 지점을 선택하면 환경 관측과 **실험용 환경 안전도**를 보여 줍니다.

## CSV 시연에서 클라우드 서비스로

초기에는 CSV 결과를 React 지도에 연결했습니다. 이후 자료가 갱신될 때마다 수동으로 파일을 바꾸는 구조를 개선하기 위해 수집·원문 보존·관측 이력·현재값 게시를 분리했습니다. 현재 사이트의 서버·DB·추론은 클라우드에서 실행하며, 로컬 컴퓨터나 Docker를 켜 둘 필요가 없습니다.

지도에서 관측 지점을 선택하거나 센서·지역명을 검색하면 조도·소음과 실제 관측 시각을 확인합니다. 오래된 관측, 입력 부족, 지원 범위 밖에서는 점수를 만들지 않습니다. 화면 새로고침은 저장된 자료를 다시 조회하며, 원천 수집이나 재학습을 시작하지 않습니다.

CCTV 조회·영상·인원 검출 기능은 제거했습니다. 현재 정기 수집 대상은 S-DoT이며, 센서 위치는 공식 공개 파일을 검증해 적재합니다.

실수집은 로컬 API와 Docker를 중지한 상태에서 확인했습니다. 응답 행과 관측·위치 이력은 장소 수나 이용자 수를 뜻하지 않습니다. 첫 정기 예약은 **2026-11-05 03:00**으로, 작성 시점에는 예약 실행 전입니다. 코드 시험과 실제 원천 수집, 일정 저장, 장기간 운영 검증을 구분합니다. GitHub Actions 성공 여부도 로컬 시험 기록과 별도로 확인해야 합니다.

## 수집에서 지도까지

| 구성 | 역할 |
|---|---|
| Sites / Cloudflare Workers | 지도 화면, 서버 API, 요청 시 추론 |
| D1 | 불변 관측 이력, 현재값, 수집 작업·페이지·완료 지점 |
| R2 | SHA-256으로 구분한 원문 응답과 이전 자료 백업 |
| 연결된 클라우드 일정 | 전날·누락 구간 수집과 최근 7일 정정 재검사 |

```mermaid
flowchart LR
    T[매일 03:00 클라우드 작업] --> S[서울시 S-DoT API]
    S --> R[(R2 원문 보존)]
    R --> V[형식·시간·페이지 검증]
    V --> D[(D1 처리 중 관측 이력)]
    D --> G{전체 페이지 완료}
    G -->|완료| P[현재값·완료 지점 원자적 게시]
    P --> F[관측과 유효한 센서 위치 병합]
    F --> M[서버 추론·지원 범위 검사]
    M --> W[지도에 관측값·점수 또는 산출 불가 표시]
```

한 요청은 최대 200행 한 페이지를 처리하며, 중단되면 저장된 다음 페이지에서 재개합니다. 전체 페이지 검증 전에는 부분 자료를 현재값으로 게시하지 않습니다. 실패나 정정을 추적할 수 있도록 원문과 이전 이력을 보존합니다. 새 관측이 들어와도 모델을 자동으로 다시 학습하지 않습니다.

| 경로 | 내용 |

클라우드 소스의 검사·빌드는 다음과 같습니다.

```sh
cd cloud
npm ci
npx tsc --noEmit
node --test tests/*.test.mjs
npm run build
```

운영 배포에는 Sites의 D1·R2, 비밀 설정, 소스 동기화·패키징 절차가 필요합니다. `npm run build`만으로 운영 저장소가 만들어지지는 않습니다. 로컬 Python 실행은 [백엔드 안내](backend/README.md), 수집 인증·재개·완료 확인은 [클라우드 운영 절차](cloud/public/CLOUD_OPERATIONS.md)를 참고하세요.

현재 RandomForest는 교체 가능한 실험용 구성입니다. 같은 입력·출력 계약을 유지하는 교체와 새 입력 변수를 추가하는 변경을 구분해 [모델 교체 안내](docs/model-replacement.md)에 정리했습니다. 새 버전은 독립 평가와 fixture 확인을 거쳐 배포합니다.

## 현재 범위와 다음 작업

센서 위치 새 파일 자동 탐지, 가로등·보안등 추가 수집은 후속 과제입니다. 검색은 관측 지점·지역명을 대상으로 하며, 임의 주소 전체의 거리 가중 평가, 안전 우회 경로, 실제 SOS 전송, 경찰서·공공기관 전화 안내는 현재 제공하지 않습니다. 현실 안전 예측력과 장기간의 부하·장애 복구는 별도 검증이 필요합니다.

API 키, 운영 토큰, DB 비밀번호, DB 덤프와 개발 캐시는 공개 저장소에 포함하지 않습니다. 원본 포트폴리오는 보존하고, 모델 내용을 제외한 최신 실적 설명서를 별도로 정리했습니다.
