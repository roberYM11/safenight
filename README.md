# SafeNight

밤길에 대한 불안에서 출발해 조도·소음과 주변 안전시설로 장소와 시간에 따른 환경을 살펴보는 프로젝트입니다.

![SafeNight 지도 화면](docs/screenshots/desktop-dark.jpg)

## 왜 만들었는가

어둡고 후미진 골목에서는 앞과 주변을 파악하기 어렵고 늦은 밤에는 도움을 청할 사람이 가까이 있는지도 알기 어렵다고 보았습니다. 그 길이 위험할지 몰라 느끼는 불안을 줄이려면 먼저 주변 환경을 판단할 정보가 필요하다고 생각했습니다.

그래서 시설이 있는지에 더해 그 시각에 실제로 얼마나 밝은지, 주변 소음은 어떤지를 함께 살펴보는 SafeNight을 만들었습니다. 소음은 사람의 활동을 가늠할 단서로 삼았습니다. 소음과 실제 유동인구의 관계는 별도 검증이 필요한 가정입니다.

## 장소와 시간 연결하기

시설 좌표는 한 장소 주변에 어떤 시설이 있는지를 보여주고 센서값은 그 장소가 특정 시각에 어떤 환경이었는지를 기록합니다. 두 자료를 센서 위치에서 연결하면 같은 장소도 시간에 따라 다르게 읽을 수 있습니다.

그래서 분석 단위를 **센서 한 곳의 특정 시각 관측**으로 정했습니다. S-DoT 환경정보의 조도·소음, 센서 설치 위치의 위도·경도, CCTV·가로등·보안등의 좌표를 하나의 관측으로 묶었습니다. 분석에는 2025-10-12에 기록된 관측을 사용했습니다.

| 자료 | 가져온 정보 | 이 정보를 넣은 이유 |
| --- | --- | --- |
| 서울 S-DoT 환경정보 | 시간별 조도·소음 최대·평균·최소 | 그 시각의 환경을 표현 |
| S-DoT 설치 위치 | 센서 ID, 위도·경도 | 서로 다른 자료를 같은 장소로 연결 |
| CCTV·가로등·보안등 | 반경 안의 좌표 행 수 | 주변 시설 분포를 표현 |

센서와 시설 사이의 거리는 Haversine 공식으로 계산했습니다. 위도·경도로 지구 표면을 따라 두 점 사이의 거리를 구해 반경 25m 안의 시설을 찾았습니다. 실제 보행 거리를 구하려면 도로와 통행 가능한 경로를 추가로 고려해야 합니다.

현재 위치의 환경은 같은 시간대의 가까운 센서 최대 8개를 거리 역수 가중 평균(IDW)으로 묶어 추정합니다. 거리 `d`를 미터로 두고 `1 / (d + 8)²`를 가중치로 써서 가까운 센서의 저장된 예측값과 환경값을 더 크게 반영합니다. 더한 8m는 아주 가까운 센서 하나의 비중이 지나치게 커지는 것을 막습니다.

## 안전도 수치화

입력은 조도 3개, 소음 3개, 소음 범위 1개, 시설 집계 3개로 구성했습니다. 조도와 소음에서는 환경 부담을 계산하고 시설에서는 보완 점수를 더했습니다.

```text
환경 부담 = 0.30 × 조도 위험 + 0.15 × 소음 위험 + 0.10 × 소음 범위 기반 위험
시설 보완 = 0.25 × CCTV 점수 + 0.15 × 가로등 점수 + 0.05 × 보안등 점수
안전도 지수 = clip(100 - 환경 부담 + 시설 보완, 0, 100)
```

이 지수는 입력한 환경 조건을 비교하기 위해 만든 평가값입니다. 실제 범죄 발생 확률과의 관계를 확인하려면 사건 관측 자료가 필요합니다. 가중치와 임계값은 [METHOD.md](docs/METHOD.md)에 공개했습니다.

## Random Forest를 사용한 이유

조도는 lux, 소음은 dB, 시설 정보는 개수처럼 서로 단위가 다른 값입니다. 또 조도와 소음에는 구간별 기준이 있고 시설 점수에는 일정 수준 이후 더 늘어나지 않는 상한이 있습니다. 한 개의 직선으로 표현하기 어려운 이런 관계를 다루기 위해 나무 기반 모델을 선택했습니다.

Random Forest는 학습 행을 중복을 허용해 무작위로 뽑는 부트스트랩으로 나무마다 다른 표본을 만듭니다. 각 나무는 입력값의 임계값으로 표본을 나누며 마지막 잎에 모인 안전도 지수의 평균을 예측값으로 삼습니다. 여러 나무의 예측을 다시 평균해 한 나무의 분할 기준에 덜 흔들리도록 했습니다. 이 프로젝트에서는 114개의 나무와 최대 깊이 18을 사용했습니다. `max_features=None`으로 설정해 각 분할에서 입력 10개를 모두 후보로 검토했습니다.

같은 좌표가 학습과 평가에 함께 들어가지 않도록 좌표별 GroupKFold 5-fold 검증을 적용했습니다. OOF는 각 좌표를 학습에서 제외했을 때의 예측을 모아 계산한 결과입니다.

| 모델 | OOF RMSE | OOF MAE | OOF R² |
| --- | ---: | ---: | ---: |
| 학습 평균값 | 9.4546 | 8.0331 | -0.0048 |
| 선형 회귀 | 7.9327 | 2.8825 | 0.2926 |
| 단일 결정나무 | 1.2337 | 0.4421 | 0.9829 |
| Random Forest | **0.8849** | **0.3505** | **0.9912** |

이 비교에서 Random Forest의 오차가 가장 작았습니다. 정해 둔 수식을 직접 계산하면 목표값과의 오차는 0입니다. Random Forest의 수치는 학습에서 제외한 좌표에서도 그 기준을 얼마나 재현하는지 보여줍니다.

## 데이터를 점검하며

센서 CSV의 열 구조를 확인하는 과정에서 헤더와 데이터의 폭이 6칸 어긋난 문제를 발견했습니다. 실제 조도와 소음 열을 기준으로 데이터를 정리하고 좌표가 뒤바뀐 센서 2곳의 11개 행을 제외했습니다. 같은 센서·시각의 반복 관측도 점검해 최종 **3,230행·652개 좌표**를 사용했습니다.

보안등 221개로 기록된 사례는 같은 좌표의 행이 반복 집계된 결과였습니다. 시설 집계가 크다는 이유만으로 안전하다고 읽으면 같은 좌표의 반복 기록까지 안전의 근거로 삼게 됩니다.

SafeNight에서는 시설의 위치와 그때의 환경을 함께 보면서 관측한 사실과 안전에 대한 가정을 구분하려 했습니다. 다음 검증에는 시설 ID로 정리한 자료와 더 긴 기간의 관측, 실제 안전 결과가 필요합니다.
